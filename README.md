# UOKU Store

Static storefront prototype for the UOKU jewelry brand.

## Preview

After GitHub Pages deployment, the site is available at:

https://milmaxved-eng.github.io/uoku-store/

## Contents

- `index.html` — storefront page
- `uoku-store.css` — responsive styling
- `uoku-store.js` — catalog, product modal, cart and demo checkout
- `fonts/` — UOKU web fonts
- `.github/workflows/pages.yml` — automatic Pages deployment

## Important

This is a visual and interaction prototype. The product illustrations, names and prices are placeholders. The cart is browser-only and the checkout form does not create orders. YooKassa, CDEK, inventory and server-side order processing are not connected.
